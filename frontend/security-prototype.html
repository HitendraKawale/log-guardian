    A small wrapper. An inspectable record.

    You register the wrapped callable with your agent. Before dispatch, it writes the tool's identity to a local journal. Afterward, it records whether the Python call returned or raised. Review compares that record with your policy.

    • AvailableGeneric Python capture, tool allowlists, local journal inspection.
    • NextAuthenticated upload, a security queue and this review timeline.
    • Not claimedAutomatic blocking, universal injection detection or proof of remote side effects.

    Inside your Python application
    policy = Policy(allowed_tools={"query_logs"})

with Monitor("run.jsonl",
             agent="incident-investigator",
             policy=policy) as monitor:
    query = monitor.wrap("query_logs", query_logs)
    result = await query(service="checkout")
    Arguments and result bodies are not stored. The first policy checks tool names, not argument values. SDK-specific adapters come later.
